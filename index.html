3. Embeddings graph

Live 3D-style projection

This graph builds simple word-context vectors from your corpus and projects them into three display dimensions. It is a classroom visualization, not embeddings from a trained LLM.

Words appearing in similar nearby contexts can appear closer in the graph.

How to read it: Each dot is a vocabulary word. Hover or tap a dot to see its token, ID and frequency. Similar positions indicate similar context patterns in this tiny sample.

4. LLM pipeline recap

Text → numerical input

Input text → tokens → vocabulary lookup → token IDs → embedding vectors.

Context → prediction

Transformer attention processes contextual information; an output layer predicts the next token.

This website demonstrates vocabulary creation, simple tokenization, token ID mapping, frequency visualization and a conceptual context-vector graph. It does not train or run a full LLM.
